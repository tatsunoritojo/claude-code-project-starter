# 0001. 匿名化した配布可能スタイルパックとして再生する

日付: 2026-05-29

## Status

Accepted

## Context

このリポジトリは元々 React Native / Habit Tracker 専用・英語・絵文字過多のプロジェクトテンプレートで、2026-05-14 に「採用されなかったテンプレート」としてアーカイブされていた。アーカイブ理由は「新規プロジェクトでは個別の CLAUDE.md を都度書き起こす運用になった」ため。

一方で、Claude Code の運用スタイル（実行ポリシー・規律・スキル）は `~/.claude/` に閉じており、他人の環境や別マシンで同じ動き方を再現できないという別の課題があった。「インストールすれば同じスタイルで動く」配布物が欲しい、という要求が出た。

## Decision

このリポジトリを、運用スタイルを**匿名化して持ち運び可能にする配布パッケージ**として再生する。

- `home-claude/`（→ `~/.claude/`）にグローバルルール・スキル・設定を置き、インストーラで展開する
- スタイル本体はグローバル CLAUDE.md として配布し、プロジェクト雛形はその一要素とする
- 完全公開・匿名化前提とし、氏名・所属・個人パス・実プロダクト名を一切含めない。プロフィールはプレースホルダ化する
- グローバルルールはプロジェクト雛形側に再掲しない（二重化＝腐敗の回避）

## Consequences

- ポジティブ: 別環境・チーム・公開先で同一スタイルを一発で立ち上げられる。アーカイブ理由（都度書き起こし）も雛形で解消
- ポジティブ: 匿名化により公開可能
- ネガティブ: スキル追加・更新のたびに個人情報トークンの grep スキャンが必須になる（完了判定に組み込んで対処）
- ネガティブ: グローバル側の個人設定とパッケージ側の汎用版が二重管理になる（パッケージは汎用版が正、と割り切る）
