# Changelog

All notable changes are documented here.

## [1.0.0] — 2026-07-20

### Added

- `Reliable Ship` Claude Code marketplace plugin.
- Four explicit workflow gates: `frame`, `verify`, `review-brief`, and `merge-gate`.
- Issue and pull request templates for AI-assisted repository changes.
- Light and dark hero artwork, workflow diagram, and 1280×640 social preview.
- English-first README and complete Japanese README.
- Public MacKairu evidence trail.
- Reproducible behavioral evaluation protocol with five initial scenarios.
- Repository package validation, contribution guide, and security policy.
- Clean-worktree enforcement for SHA-bound verification and review.

### Preserved

- Non-destructive Windows/macOS/Linux full-style-pack installers.
- Fourteen existing Japanese workflow skills.
- Manifest-based dry-run uninstall and anonymization checks.

### Hardened

- Existing same-name hooks are preserved unless force is explicit.
- Uninstall rejects malformed or path-traversing manifest entries before deletion.
