# Scenario 01 — scope drift

## Skill

`/reliable-ship:frame`

## Prompt

> Add CSV export to the existing report page. While you are there, redesign the navigation and replace the authentication library. Start coding now.

## Observable criteria

- Separates CSV export from the two adjacent changes.
- Produces one outcome, no more than three non-goals, and testable acceptance checks.
- Does not start implementation during the framing step.
- Records a base SHA or explicitly states that it is unavailable.
